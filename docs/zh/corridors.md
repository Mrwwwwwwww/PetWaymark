# 走廊候选与未覆盖边界

2026-10-08。以下是研究清单，**15 条候选全部 `unsupported`，可确认可行线路为 0**。箭头表达待比较的地理接驳，不表示存在直飞、宠物仓位、铁路产品或获准口岸。

首批限单只自有犬猫、个人非商业移动；单独运输与法律分类分开记录。每个国际方向计划做犬／猫 × 主人同行／宠物与主人分开旅行四类输入，共 24 个研究场景；超出用途条件须识别并返回未覆盖原因，不套普通旅行链。

## 六个跨境方向

| ID | 方向／小城联运样例 | 独立核对重点 |
|---|---|---|
| INT-CN-US | CN→US：湖州 → PVG → LAX → Ventura | 中国出境；美国犬旅行史与猫独立分支；CA 叠加；实际产品与口岸设施 |
| INT-US-CN | US→CN：Ventura → LAX → PVG → 湖州 | APHIS 对华出口；中国携带与独行进口分类；隔离／口岸附件；回国接驳 |
| INT-CN-EU | CN→EU：清远 → CAN → FRA → Marburg | 中国出口；欧盟首入境与最终目的地；检测／证书版本；德国本地叠加 |
| INT-EU-CN | EU→CN：Marburg → FRA → CAN → 清远 | 德国属地出口证书／背书；中国独立入境链；不能反转 CN→EU |
| INT-US-EU | US→EU：Kingston（纽约州）→ JFK → AMS → Delft | 纽约州起运；APHIS 对荷出口；欧盟及荷兰；再另建美国→德国样例 |
| INT-EU-US | EU→US：Delft → AMS → JFK → Kingston（纽约州） | 荷兰出口；美国犬旅行史／接种地分支；猫独立分支；纽约州；DE／FR 另核 |

EU 不是单一落地国。德、法、荷均为首批深核目标：每个涉及 EU 的方向要另建 DE／FR／NL 子范围；上表只选一个具体小城场景展示，不能以此宣称其余成员国已覆盖。首入境国与最终目的国分别记录；返程单独建立条件。

## 首批国内与欧盟内部走廊

| ID | 候选 | 比较任务 |
|---|---|---|
| DOM-CN-EAST | 湖州 → PVG → CAN → 清远 | 华东起点：比较分日自驾、专车候选、陆空、铁路候选；两端检疫与交接 |
| DOM-CN-SOUTH | 清远 → CAN → PEK → 廊坊 | 华南起点：比较全陆路与陆空；铁路实际站点／车次另查 |
| DOM-US-CA | Ventura（CA）→ LAX → DFW → Denton（TX） | 加州小城接驳；目的德州要求；旅客产品／货运分离 |
| DOM-US-NY | Kingston（NY）→ JFK → LAX → Ventura（CA） | 纽约州小城接驳；加州目的州要求及临时措施 |
| DOM-US-TX | Denton（TX）→ DFW → JFK → Kingston（NY） | 德州小城接驳；纽约州目的要求；长途自驾与陆空比较 |
| DOM-EU-DE | Marburg → Frankfurt am Main → Heidelberg | 德国国内陆路／铁路候选；使用 FRA 作为枢纽研究点，不虚构国内航段 |
| DOM-EU-FR | Senlis → Paris → Chartres | 法国国内陆路／铁路候选；CDG 接驳研究；铁路运营商规则待补 |
| DOM-EU-NL | Delft → Amsterdam → Alkmaar | 荷兰国内陆路／铁路候选；AMS 接驳研究；运营商规则待补 |
| INTRA-EU-DE-NL | Marburg → Frankfurt am Main → Amsterdam → Delft | 跨成员国陆路／铁路，区分欧盟内部移动与外部首入境 |

中国两组分别由华东、华南起运；美国三组覆盖加州、纽约州、德州小城接驳；欧盟为德、法、荷各一本国内样例，另有 DE→NL 跨成员国样例。所有专车均为模式候选，当前无已核实服务商。

机场研究池为 PVG／PEK／CAN、JFK／LAX／DFW、FRA／CDG／AMS。代码只是候选标签；宠物品类、货站、查验设施、营业时间、首末段交接及航司具体产品都要单独核实。无距离、时刻、报价或仓位依据时不填数。

## 来源与开放门槛

[机器清单](../../data/coverage/week1-candidates.json)与[官方入口队列](../../data/sources/week1-research-index.json)按 `source_ids` 关联；这些入口沿用规划资料，状态仍是待逐条核实。航司、铁路实际产品、口岸附件、地区出口程序是显式缺口，尚无足够依据开放路线。

每条候选后续需：用途分类→始发／中转／首入境／最终地规则→实际承运产品与设施→分段交接和时间轴→犬猫正反例→合格人类复核。800 公里只作为可配置产品偏好，不能越过上述硬条件；无路网里程时不据地名推算阈值。

未覆盖：港澳台；美国其余州、夏威夷与领地；欧盟其余 24 国地方规则；英国、瑞士及第三国中转；多宠、其他物种、所有权转移／出售／领养的完整流程；服务犬专门规则。幼龄、短鼻、健康风险、授权陪同日期错位须保留阻塞或人工核实入口。全陆路跨海不成立；独行货运不自动等于商业进口。

国内候选不自动双向可用；反向、换航司、换口岸、换出行日期都需独立检查。正式规则为 0，`null` 不表示无要求，任何候选不代表可预订。
