# v0.1.0 — early research preview / 早期研究预览

Demo / 演示：https://mrwwwwwwww.github.io/PetWaymark/

## Release boundary / 发布边界

All 15 rule records remain unreviewed drafts. Zero verified feasible routes. No
booking, order acceptance, live inventory, quotation or confirmed transport service.
This user-authorized release distributes research software, not reviewed travel
permission. Stage A's independent human-review and voluntary user-understanding
gates have not passed; affected directions remain unsupported.

15条规则均为待核草稿，已验证可行路线为零。非订舱、非接单，没有实时库存、
报价或确认服务。用户授权发布的是研究软件；A阶段独立人工复核与真实试用理解
验收尚未通过，相关方向保持未覆盖，不能据此判断实际可出行。

## Included / 包含

- Offline deterministic Python engine/CLI and anonymous local bilingual input form.
  国内候选、六国际方向独立犬猫文件链、时间轴、费用未知项、名录和交接诊断。
- Static bilingual demo generated by the same CLI from 22 fixed synthetic fixtures;
  printable checklists and synthetic-only JSON download. Custom input assessment is
  available in the local web app, not GitHub Pages. 22个固定合成样例、双语打印与导出。
- 48 executed synthetic regressions, with a reproducible six-direction matrix.
  合成案例不计用户、采用或法律验证。
- Independently versioned curated draft dataset `2026.10.08-draft.1`, file hashes and
  reproducible archive; existing component dataset versions remain for historical
  reproduction. 引擎版本`0.1.0`与数据包版本分开，内部历史版本不重写。

## Reproduce / 复现

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python scripts/check_scaffold.py
.venv/bin/python scripts/validate_data.py
.venv/bin/python scripts/audit_coverage.py --check
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python scripts/package_data.py --check
.venv/bin/python scripts/package_data.py
.venv/bin/python scripts/build_pages.py
.venv/bin/python -m apps.web.server --port 8766
```

Browser gates require Playwright 1.64.0 and Chromium; see the CI workflow.
Data archive hashes are in `SHA256SUMS` on the release; unpack the archive at a
repository root to use existing loaders. `data/VERSION.json` records every data file
hash except itself. No schema migration: this release adds a package manifest only.
A data edit requires an explicit dataset version decision and regeneration of hashes;
CI refuses manifest drift. Current requirements must be rechecked before travel.

## Outstanding / 未完成

Independent qualified human review, complete current official annexes and local
requirements, date-specific whole-route capacity/care, real voluntary feedback and
independent adoption remain absent. Transit, unaccompanied cargo, service animals,
multi-pet and non-owned movements are outside compiled scope. No claim of full
China/US/EU coverage. No known blocking software defect in the released fixed demo
scope after the technical checks; this does not close the evidence gaps.

独立人工复核、完整现行附件与地方要求、真实全程运力照护、真实反馈和独立采用
均未完成。过境、独立货运、服务动物、多宠及非自有用途未编译；不声称完整覆盖。
