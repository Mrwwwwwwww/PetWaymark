# Security / 安全

This is an unreleased documentation scaffold; there are no supported application versions or deployed services.

Never put secrets, passports, chip IDs, precise addresses or customer records into public issues, fixtures or logs. Share only minimal synthetic reproductions. Ordinary source/rule corrections can use the rule issue template after launch.

No private security inbox or hosted advisory channel has been configured. Before public launch the owner must establish and verify a private channel, publish it here and define supported versions. Until then, keep sensitive findings local and relay them only through an existing private channel to the project owner. Do not invent an email address or promise a response SLA.

If a rule defect could mislead travelers, mark the affected coverage disputed/unsupported, retain the evidence and version history, then review the correction before restoring conclusions. A documentation checker is not a legal or security audit.
